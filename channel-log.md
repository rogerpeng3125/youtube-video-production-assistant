# Channel log

Running record of how each published video actually performed, written by hand
after posting. **The Research & strategy agent reads this file at the start of
every cycle** — it is the only feedback loop in the pipeline. An empty or stale
log means step 1 is guessing.

Newest entries at the top. One entry per published video.

Suggested shape for an entry (adapt freely — this is for your use, not a schema):

```
## YYYY-MM-DD — 001-slug — "Video title as published"
- **Views / retention:** at 7 days, at 30 days; where the drop-off is
- **Shorts:** which clips went out, how each did
- **Comments:** recurring questions, confusions, requests
- **What worked:**
- **What didn't:**
- **Follow-up idea this suggests:**
```
